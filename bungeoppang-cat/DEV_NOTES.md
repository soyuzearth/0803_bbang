# 붕어빵 먹는 고양이 개발 기록

## 게임 컨셉

- 제목: 붕어빵 먹는 고양이
- 장르: 모바일 가로형 원버튼 러너 게임
- 조작: 화면 탭, 클릭, 스페이스바, 점프 버튼
- 핵심 루프: 고양이가 앞으로 달리며 붕어빵을 먹고 장애물을 피한다.

## 기획 변화

1. 처음에는 붕어빵을 타이밍에 맞춰 굽는 게임을 검토했다.
2. 이후 더 직관적인 원버튼 게임으로, 고양이가 걸어가며 붕어빵을 먹는 러너 구조로 변경했다.
3. 팥붕은 기본 점수, 슈붕은 콤보 아이템으로 정했다.
4. 탄 붕어빵은 피해야 하는 장애물로 추가했다.
5. 모바일 가로 화면에 맞춰 HUD와 점프 버튼을 게임 화면 안으로 재배치했다.
6. 목숨 3개와 로컬 랭킹 입력 기능을 추가했다.
7. 물웅덩이 장애물과 붕어빵 봉지 보너스를 추가해 러너 게임성을 강화했다.

## 현재 규칙

- 팥붕: 기본 점수 획득
- 슈붕: 높은 점수 획득 및 콤보 증가
- 탄 붕어빵: 맞으면 목숨 감소
- 물웅덩이: 점프해서 피해야 하며, 닿으면 목숨 감소
- 붕어빵 봉지: 일정 시간 점수 2배 보너스
- 목숨: 3개
- 목숨이 0이 되면 게임오버
- 게임오버 후 이름을 입력해 로컬 랭킹 Top 5에 저장

## 비주얼 방향

- 첨부 이미지 스타일을 참고한 플랫한 겨울 일러스트 톤
- 배경: 겨울 밤거리, 붕어빵 노점, 가로등, 초승달, 눈
- 고양이: 달리기/점프 스프라이트 2종
- 붕어빵 아이템: 팥붕, 슈붕, 탄 붕어빵
- 버튼: 붕어빵 아이콘이 들어간 원형 모바일 게임 버튼
